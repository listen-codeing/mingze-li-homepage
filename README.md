# Mingze Li Academic Homepage

This folder contains a complete static academic homepage for Mingze Li. It opens directly in a browser and can be hosted for free on GitHub Pages.

## Files

- `index.html` - page structure and sections
- `styles.css` - visual design and responsive layout
- `site-data.js` - your editable personal information
- `main.js` - renders the page from `site-data.js`
- `assets/` - profile image, favicon, and research visual

## Customize

Edit `site-data.js` first. Replace:

- `name`, `initials`, `title`, `summary`, `bio`
- `email`, `affiliation`, `location`
- `cvUrl`, `scholarUrl`
- `quickFacts`, `info`, `research`
- `publications`, `projects`, `talks`

The homepage currently uses `assets/mingze-li.svg` as the profile image.

## Free Deployment With GitHub Pages

1. Create a GitHub repository.
2. Upload all files in this folder.
3. Open the repository settings.
4. Go to Pages.
5. Choose `Deploy from a branch`.
6. Select the `main` branch and the root folder.
7. Save and wait for the published URL.

The default GitHub Pages URL is free. A custom domain is optional and usually costs money through a domain registrar.
